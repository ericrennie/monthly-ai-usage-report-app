Guided collection

Configure sources. Generate one report.

Collect a daily, weekly, monthly, or custom period from Claude Code on Amazon Web Services (AWS) Bedrock, local Codex telemetry, and Circuit without editing scripts.

Local and ephemeral by design

The app binds to 127.0.0.1. Temporary AWS credentials stay in process memory for one collector run and are never saved, logged, or placed in browser storage. Prefer an AWS profile or single sign-on whenever available.

Claude Code on AWS Bedrock

Portable rolling-day collector.

The Python collector can be stored anywhere on this device. Examples: ~/tools/bedrock_usage_check.py on macOS/Linux or C:\Users\your-name\Tools\bedrock_usage_check.py on Windows.
Credential method
Refresh AWS single sign-on before running when credentials have expired.
Confirm ownership with the collector owner. Only AWS Lambda Function URLs are accepted.
3

Codex and ChatGPT

Exact local date-range telemetry.

The folder can be anywhere. Typical examples: ~/.codex/sessions on macOS/Linux or C:\Users\your-name\.codex\sessions on Windows. The collector scans JSONL rollouts and keeps reasoning tokens inside output totals.
No Codex credentials required

The local collector reads only the selected sessions directory. It cannot provide authoritative ChatGPT subscription billing.

Circuit

Capture visible dashboard totals or enter verified figures.

Circuit source
Open the dashboard and sign in normally. Browser security prevents this localhost app from reading another website directly, so copy the visible dashboard page text and let the app extract the month-to-date totals.

Read month-to-date totals from copied dashboard text

On the dashboard, select the visible page text (Ctrl+A/Cmd+A) and copy it. Return here and choose Read copied dashboard text. You can also paste text below.
Allowed only during the second month of a calendar quarter. The report labels the result as Inference and shows the arithmetic.

Important boundaries

    
Bedrock collection is a rolling number of days ending on the retrieval date and may not match a historical custom range. Local Codex telemetry is not authoritative ChatGPT billing. Circuit values must be reviewed by the user because browser same-origin controls prevent automatic reading of an authenticated dashboard in another tab.
