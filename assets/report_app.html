Local and ephemeral by design

The app binds to 127.0.0.1. Temporary AWS credentials stay in process memory for one collector run and are never saved, logged, or placed in browser storage. Prefer an AWS profile or single sign-on whenever available.

At startup, the app automatically populates this field when the detected collector contains a configured DEFAULT_LAMBDA_URL. It does not search your AWS account. Verify the displayed URL before approving egress. This is not a Bedrock model endpoint, AWS sign-in page, function Amazon Resource Name (ARN), or access key.
What is this URL, and where do I find it?

What it does: The local Python collector sends a signed request to an AWS Lambda function that queries the approved usage data and returns the report figures.

First ask the collector owner: If your team supplied the collector script, the URL may populate automatically. Otherwise ask the administrator who deployed the Bedrock usage collector for its approved Function URL.

Find it in the AWS console:

  1. Open AWS Console > Lambda > Functions.
  2. Select the function that actually runs your Bedrock usage collector.
  3. Open Function overview, or Configuration > Function URL.
  4. Copy the Function URL and verify that its authentication type is AWS Identity and Access Management (AWS_IAM).

Command line: aws lambda get-function-url-config --function-name <collector-function-name> --query FunctionUrl --output text

Example: https://abcde12345.lambda-url.us-east-1.on.aws/

If the collector Lambda does not exist, creating a Function URL by itself is not enough—the collector owner must deploy the usage-collector function and grant your AWS identity permission. Do not enter an unverified or public (NONE authentication) endpoint. See the AWS Function URL instructions.

Important boundaries

    
Bedrock collection is a rolling number of days ending on the retrieval date and may not match a historical custom range. Its Function URL must point to the approved usage-collector Lambda, not a Bedrock endpoint or arbitrary Lambda. Codex reports No Billing available. Circuit reports No Billing available unless approximate cost is extracted from user-pasted dashboard text. Circuit values must still be reviewed because browser same-origin controls prevent automatic reading of an authenticated dashboard in another tab.
